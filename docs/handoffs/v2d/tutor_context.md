# V2d context for the separate tutor

Recorded 2026-10-12. Supports a separate tutoring conversation assuming
introductory physics, single-variable calculus and basic Python. It does not
assert lesson completion, change learning records, restart the course or gate
approved engineering on teaching.

The bench's polarization mode presents the unchanged V2c Jones model. A sampled
point has two complex numbers, the x/y components of one transverse field;
they are not the two optical ports of the two-path experiment. The source has
a spatial scalar envelope, and explicitly shown coefficients prepare the
incident vector without automatic normalization.

An ideal polarizer projects that vector onto its declared axis and can lose
norm. A retarder changes the relative phase of axis/perpendicular components;
QWP/HWP are explicit numerical retardances. The chosen returned common phase
also remains part of the vector. Order can therefore change later output.
All elements act at one common plane: attractive mesh spacing adds no travel,
extra phase, thickness, material or aperture.

Total intensity can stay unchanged while complex polarization changes. A
diagonal input passing a zero-axis QWP is a useful example. Compare the actual
returned components and a shared-phase marker, not just the intensity image
or ellipse outline. Multiplying both components by a common complex phase
can preserve the ellipse's shape but shift its tau-zero real vector.

The displayed real vector is Re([Ux,Uy]*exp(-i*tau)), with +y downward and equal
component scales. Tau is a dimensionless slow illustration. Avoid ambiguous
right/left circular labels; use explicit (1,+i)/sqrt(2) and (1,-i)/sqrt(2).
Camera movement, selection, colors and playback only change presentation.

Stage norms use relative field units times area, not calibrated watts.
Adjacent and original-incident ratios have different denominators. A zero
denominator gives null, not an epsilon-based number. Arbitrary coefficients
change incident norm; a ratio alone does not prove amplification/causality.
Crossed and middle-polarizer presets start from already x-polarized light.

Exactly zero returned complex components mean no defined polarization at that
sample. Tiny nonzero components may have rounded-zero intensity or motion too
small to draw; do not call either case unpolarized light. Any magnification
must be disclosed and does not change the raw scientific result.

Each sweep angle is a new public full-train calculation from the same incident
field. Endpoints are retained, and failures show only genuinely completed rows.
Selecting a point does not calculate; applying its angle and requesting full
results is a separate intentional action. Choosing another complex sample
also requires an explicit operation.
