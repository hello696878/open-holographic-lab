calibrated watts, detector irradiance, beam width, a diffraction calculation,
side-scattering measurement or a wave-field attachment to folded paths.
Display thickness/glow, mounts, labels and direction markers are presentation
only. Actual returned finite endpoints, media and event state govern readouts;
overlapping physical paths are not displaced to improve apparent separation.

two preset origin triples. Zero/one finite closed convex block/right triangular

dispersion, absorption in dielectric, curved/nested/overlapping/imported bodies,
multiple bodies, source bundles, arbitrary polarization editor or scene
persistence is included.

Each ray retains its own power-coherency matrix and phase relation between its
transverse components. Different paths are added **incoherently** at receivers.
That compulsory assumption is not established by source monochromaticity, a
random mask or the visual display. No coherent slab/etalon fringes, inter-path
phase, receiver polarization matrix or common-plane analyzer is claimed. A
phase-sensitive downstream operator in independent tests is algebraic evidence,
not an added apparatus or physical receiver model. TIR includes reflected s/p
phase but no evanescent-field display or propagating transmitted ray.
