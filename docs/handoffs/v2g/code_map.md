layers and original failures from later corrections. The three PNGs in
`figures/` are genuine browser captures of raw/analyzed results, a calculated

root exports, M5 bundle contracts, Streamlit apps, dependencies/lockfiles,

UI rendering and file I/O remain outside the numerical core.
