# Context for the separate tutor

This handoff supports teaching; it does not record a completed lesson or restart
the learner's course. Engineering validation proceeds independently. Assume
introductory physics, single-variable calculus and basic Python.

Begin with two different labels: an optical port identifies a path/output;
x and y label transverse polarization components within each path. The ideal
splitter mixes matching components between ports. It does not exchange x and y.
Then distinguish a complex field, its squared-magnitude intensity and a sampled
norm. The intensity display cannot reveal all relative complex phase information.

Useful experiments after the tutor chooses them:

1. Identical lossless arms: change the explicitly entered common arm phase and
   deliberately simulate. Compare the two raw output fractions.
2. Orthogonal arms: use the half-wave plate preset. Explain why orthogonal
   polarization removes the raw cross term without erasing either path.
3. Common output analyzers: enable the same pi/4 analyzer on each raw output.
   Compare raw and analyzed images on one shared scale. Discuss why the analyzer
   permits interference in projected fields while removing norm. Contrast the
   original-input fraction with transmission relative to one raw port.
4. Reorder a retarder and polarizer in one arm. The ordered matrices generally
   do not commute. Preserve their complex phase rather than replacing the
   retarder with a real arrow rotation.
5. Perform the explicit 17-point phase sweep. Both endpoints are separate
   calculations and may differ by a tiny floating-point residual. Choosing a
   marker is a view action; obtaining a full image at that phase is a separate
   deliberate calculation.

The application validates static settings before simulation. Explain that
derived weak fields can still leave the supported numerical domain. A genuine
analyzer failure is a failed requested measurement even if the raw solver ran.
Display preparation failure is different: the numerical result may be retained
for an explicit presentation retry, without another optical calculation.

Settings documents transfer a scientific recipe and literal notes. Applying a
preview restores a not-yet-simulated draft. Version 1 supports the earlier three
modes, and version 2 only the new polarized two-path mode. Neither document is a
saved experimental result or a qualification badge. Releasing retained results
frees calculations in every mode while preserving settings and useful documents;
it performs no new science. A later calculation must again be deliberate.

Keep claims within the ideal periodic, aligned, low-angle envelope model. No
reflection law, material/coating, vector Maxwell, quantum or calibrated-watt
claim follows from these demonstrations. Refer to the normative conventions and
the dated evidence handoff when discussing tiny residuals or tolerances.
